# 🌿 Ecobazar: Online Grocery Store

A modern, responsive e-commerce website for fresh and organic groceries, built with **HTML, CSS and vanilla JavaScript**. It covers the complete shopping journey: from signing in and browsing products to checkout and live order tracking.

🔗 **Live Demo:** [Add your live link here](#)

---

## ✨ Features

### 🔐 Authentication

- Sign up, sign in and logout
- "Remember me" option and personalised greeting

### 🛍️ Shopping Experience

- 12 product categories (Fruits, Vegetables, Meat & Fish, Snacks, Beverages and more)
- Filter by category and price range, with sorting options
- Sale badges, star ratings and a dedicated **Hot Deals** page
- Wishlist and quick-view options on every product

### 🛒 Cart and Coupons

- Instant "added to cart" notifications
- Live cart total in the header
- Update quantities, remove items or clear the cart
- Coupon codes with real-time price updates

### 💳 Checkout

- Billing details form with live order summary
- Payment options: Cash on Delivery, Credit / Debit Card, Apple Pay

### 📦 Orders and Tracking

- Order history with date, items, total and status
- Step-by-step tracking: Order Placed → Processing → Shipped → Out for Delivery → Delivered

### 👤 User Account

- Profile dashboard with orders, wishlist and cart summary
- Update name and password

### 📝 Blog and Pages

- Blog articles with tags, recent posts and a comment section
- About Us and Contact pages with a message form

### 🌍 Extras

- Multi-language support: English, Español, اردو
- PKR currency, newsletter subscription and back-to-top button
- Fully responsive design for desktop, tablet and mobile

## 🚀 Getting Started

**1. Clone the repository**

```bash
git clone https://github.com/umarraja61933/ecobazar-ecommerce.git
```

**2. Open the project folder**

```bash
cd ecobazar-ecommerce
```

**3. Run the website**

Open `index.html` in your browser, or use the **Live Server** extension in VS Code.

---

## 🧭 Website Flow

1. 🔐 **Sign up or sign in** to enter the store
2. 🏠 **Explore the Home page** and choose a category
3. 🛍️ **Browse products** in Shop and use filters to find items
4. ❤️ **Add items** to your wishlist or cart
5. 🎟️ **Open the cart**, update quantities and apply a coupon
6. 💳 **Checkout** by entering billing details and selecting a payment method
7. ✅ **Place the order** and receive your order number
8. 📍 **Track the order** from Pages → Track Order
9. 📜 **View past orders** in Order History and manage details in My Account
